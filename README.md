# promptwiki/content

PromptWiki의 Markdown 문서 저장소입니다.

이 레포에 직접 기여하거나 PR을 제출하는 것으로 문서를 추가하거나 수정할 수 있습니다.

## 기여하기

1. 이 레포를 Fork합니다.
2. 문서를 작성하거나 수정합니다. ([문서 구조 가이드](https://github.com/promptwiki/.github))
3. PR을 제출합니다.
4. 리뷰 후 머지됩니다.

## 디렉터리 구조

```
{lang}/          # ko 또는 en
  {purpose}/     # guide | rule | template | example | reference
    {level}/     # beginner | intermediate | advanced
      {slug}.md
```
