## 왜 중요한가

같은 질문이어도 배경 정보의 양에 따라 AI의 답변 품질이 극적으로 달라진다.

AI는 당신에 대해 아무것도 모른다. 당신이 누구인지, 무슨 일을 하는지, 왜 이 질문을 하는지 전혀 모른 상태에서 답변을 생성한다. **당신이 알려주지 않으면 AI는 가장 일반적인 답변을 줄 수밖에 없다.**

---

## Before / After

### 컨텍스트 없는 질문

```
이메일 써줘.
```

AI의 답변: 누구에게 쓰는 이메일인지, 목적이 무엇인지 모르기 때문에 극히 일반적인 예시 이메일을 생성한다.

---

### 컨텍스트를 충분히 준 질문

```
나는 스타트업의 마케팅 담당자야.
어제 미팅에서 만난 잠재 고객(IT 기업 대표)에게 팔로업 이메일을 써야 해.

상황:
- 우리 제품: B2B SaaS 마케팅 자동화 툴
- 미팅 내용: 데모를 보여줬고 반응이 좋았음
- 목적: 다음 단계(무료 체험 제안)로 이끌기
- 톤: 전문적이지만 너무 딱딱하지 않게

길이는 3~4문단 이내로 부탁해.
```

AI의 답변: 상황에 딱 맞는 이메일을 구체적으로 작성한다.

## 포함하면 좋은 컨텍스트 5가지

### 1. 나는 누구인가 (배경)
```
나는 비전공자로 최근 파이썬을 배우기 시작했어.
나는 10년 경력의 백엔드 개발자야.
나는 중학교 과학 선생님이야.
```

### 2. 목적이 무엇인가 (Why)
```
이 코드를 팀원에게 설명하려고 해.
이 글을 블로그에 올릴 예정이야.
면접 준비를 위해 개념을 정리하고 싶어.
```

### 3. 현재 상황 (Context)
```
지금까지 이렇게 시도해봤는데 잘 안 됐어: [내용]
우리 팀은 React를 쓰고 있어.
예산 제약으로 무료 툴만 사용 가능해.
```

### 4. 원하는 형식 (Format)
```
번호 목록으로 정리해줘.
한 문단으로 간결하게.
표 형식으로 비교해줘.
초등학생도 이해할 수 있는 수준으로.
```

### 5. 제약 조건 (Constraints)
```
500자 이내로.
전문 용어 없이.
한국어로만.
```

## 실전 템플릿

질문하기 전에 이 구조를 참고한다.

```
[나는 누구인가]
나는 [역할/상황]이야.

[상황 설명]
지금 [무엇을 하고 있는지/무슨 문제가 있는지].

[목적]
[왜 이걸 해결해야 하는지/결과물을 어디에 쓸 것인지].

[요청]
[구체적인 요청 내용].

[형식 요구사항] (선택)
[길이, 형식, 톤 등].
```

---

## 자주 하는 실수

**"이미 알겠지"라고 가정하기**
AI는 이전 대화를 기억하지 못한다. (새 대화를 시작하면 완전 초기화)
매 대화 시작 시 필요한 배경을 다시 제공한다.

**너무 짧게 질문하기**
"좋은 글 써줘"보다 어떤 주제로, 누구를 위해, 어떤 목적으로 쓰는 글인지 알려준다.

**컨텍스트를 한 번에 몰아서 주지 않기**
필요한 정보를 처음부터 충분히 제공하면 왔다갔다 하지 않아도 된다.
