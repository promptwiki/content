# 용어집

PromptWiki에서 사용하는 주요 용어를 정의합니다.

## Prompt
AI에게 전달하는 입력 텍스트. 명령, 질문, 맥락 등을 포함한다.

## Context Window
AI 모델이 한 번에 처리할 수 있는 텍스트의 최대 범위. 토큰 단위로 측정된다.

## Frontmatter
Markdown 파일 상단의 YAML 메타데이터 블록. `---`으로 감싼다.

## Status
문서의 검토 상태. draft → review → stable → recommended 순으로 진행된다.
